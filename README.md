## Descargar ejecutable para Windows

La versión ejecutable de **Pose Challenge AI** está disponible en Google Drive:

[Descargar Pose Challenge AI para Windows](https://drive.google.com/file/d/1Jeg-10gx8nCQLfy_g-fE-l3dYoAmK3Rh/view?usp=drive_link)

### Requisitos

- Windows 10 u 11
- Camo Studio
- iPhone con Camo Camera

### Cómo ejecutar

1. Descargar `PoseChallengeAI_Windows.zip`.
2. Extraer completamente el archivo ZIP.
3. Abrir Camo Studio.
4. Conectar o emparejar el iPhone.
5. Comprobar que Camo Studio muestra la cámara del iPhone.
6. Abrir la carpeta extraída `PoseChallengeAI`.
7. Ejecutar `PoseChallengeAI.exe`.
8. Presionar `ENTER` para comenzar el juego.

> Importante: no ejecutar `PoseChallengeAI.exe` directamente dentro del archivo ZIP. Primero se debe extraer toda la carpeta, ya que el programa necesita los archivos incluidos en `_internal`.
